# La Esencia del Alma

Repositorio asociado al sitio profesional **La Esencia del Alma**, publicado en:

**[https://laesenciadelalma.com/](https://laesenciadelalma.com/)**

## Descripción

Proyecto web para una clienta real. El sitio está disponible públicamente en su dominio y el repositorio contiene los archivos del sitio estático: páginas HTML, hojas de estilo, imágenes y archivos de soporte para buscadores.

Este README documenta la relación entre el repositorio y la demo pública sin exponer datos privados ni información de contacto no destinada a esta documentación.

## Archivos principales

- `index.html`: página principal.
- `formulario.html`: página de formulario.
- `style.css` y `styles.css`: hojas de estilo.
- `robots.txt` y `sitemap.xml`: archivos para rastreo e indexación.

## Vista local

El repositorio no requiere instalación de paquetes. Con Python instalado, desde la carpeta del proyecto ejecutá:

```bash
python -m http.server 8000
```

Después abrí [http://localhost:8000](http://localhost:8000).
